# TC-05 新字段写入与零值规则

## 用例编号与名称

TC-05 新字段写入与零值规则（`TestLR03_NewFieldsWriteAndZeroRules`）

## 所属场景

LR03 MySQL 写入场景（scenario-LR03-mysql-write）

## 版本声明

- `log-reader`：当前源码版本（`mod_log_mysql` 99 列，`bfe-access-pb` v0.3.7/3.8/3.9 字段）
- 表结构：ai-gateway-api 权威 `db_ddl_report_mysql.sql` 明细表 99 列版内嵌副本（含 2026-09-27 加列）

## 测试目的

验证 ai-cache / 流量镜像 / ai-intent 10 个新列（`ai_cache_status`、`mirror_hit`、`mirror_cluster`、`ai_intent_question`、`ai_intent_answer`、`ai_intent_confidence`、`ai_intent_source`、`ai_intent_latency_us`、`ai_intent_cache_hit`、`ai_intent_questions_version`）的端到端写入：

1. 新字段全部填充时，MySQL 各列取值与 pb 输入精确一致，重点覆盖 `ai_intent_confidence` 浮点列与 `mirror_hit`/`ai_intent_cache_hit` 的 proto bool → TINYINT(0/1) 转换；
2. 未启用缓存/镜像/意图的最小日志（新字段全部未设置）时，各新列落 mapper 定义的缺省值，且不违反 DDL 约束。

## 运行模式

单组件模式：真实 `log-reader` 进程 + 真实 MySQL。

## 前置条件

同 TC-01。

## 配置构造

同 TC-01。

## 输入数据

- **Part 1（全字段）**：`common.MakeRequestLog(82001, ...)`，该构造器填充全部 10 个新字段（`ai_cache_status=hit`、`mirror_hit=true`、`mirror_cluster=mirror-cluster-A`、`ai_intent_question=intent-q-001`、`ai_intent_answer=intent-a-1`、`ai_intent_confidence=0.95`、`ai_intent_source=llm`、`ai_intent_latency_us=1234`、`ai_intent_cache_hit=true`、`ai_intent_questions_version=v2026-09-27`）。
- **Part 2（零值/缺省形态）**：手工构造的最小日志（`logid=82002`），仅设置必填字段与 `ai_requested_model=zero-intent-model`，不设置任何缓存/镜像/意图字段。
- **Part 3（显式置 0）**：`MakeRequestLog(82003, ...)` 后显式将三个可空数值列置零（`ai_intent_confidence=0`、`ai_intent_latency_us=0`、`ai_intent_cache_hit=false`），验证"求值为零"与"未求值（NULL）"可区分。

## 操作步骤

1. 准备环境并启动 `log-reader`。
2. 写入 Part 1 日志，轮询等待表行数 ≥ 1（超时 20s）。
3. 按 `logid = 82001` 查询并逐列断言 10 个新列取值。
4. 写入 Part 2 日志，轮询等待表行数 ≥ 2（超时 20s）。
5. 按 `logid = 82002` 查询并逐列断言缺省形态。
6. 写入 Part 3 日志，轮询等待表行数 ≥ 3（超时 20s）。
7. 按 `logid = 82003` 查询并断言三个可空数值列为 0（非 NULL）。

## 预期结果

**Part 1（全字段精确断言）**：

- `ai_cache_status = 'hit'`、`mirror_cluster = 'mirror-cluster-A'`、`ai_intent_question = 'intent-q-001'`、`ai_intent_answer = 'intent-a-1'`、`ai_intent_source = 'llm'`、`ai_intent_questions_version = 'v2026-09-27'`。
- `mirror_hit = 1`、`ai_intent_cache_hit = 1`（proto bool true → TINYINT 1）。
- `ai_intent_confidence = 0.95`（DOUBLE 浮点精确相等）、`ai_intent_latency_us = 1234`。

**Part 2（零值/缺省形态）**：

- NOT NULL 字符串列写空串而非 NULL：`ai_cache_status = ''`、`mirror_cluster = ''`、`ai_intent_question = ''`、`ai_intent_answer = ''`、`ai_intent_source = ''`、`ai_intent_questions_version = ''`（mapper `kindNotNullStr`：空串原样写入，避免 Error 1048）。
- `mirror_hit` 为 NOT NULL TINYINT 列：未设置 → 0。
- 三个可空数值列按 proto 指针判空（mapper `kindOptionalNum`），未设置 → **NULL**（= 未求值，与 report.md 契约对齐）：`ai_intent_confidence IS NULL`、`ai_intent_latency_us IS NULL`、`ai_intent_cache_hit IS NULL`。

**Part 3（显式置 0）**：

- `ai_intent_confidence = 0`、`ai_intent_latency_us = 0`、`ai_intent_cache_hit = 0`，均非 NULL——消费侧可区分"求值为零"（0）与"未求值"（NULL）。

## 清理

停止 `log-reader` 进程，关闭数据库连接，DROP 测试专用数据库，删除临时目录。
